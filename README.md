# THOR STEINAR — пробная версия с реальными товарами

Актуальный сайт: React + Vite, немецкий интерфейс, оригинальный логотип и шесть настоящих товаров Thor Steinar: EIKIN II, LINES, SUPPORT 2.0, HALSA, LEGENDARY и Damen SUPPORT. Карточки используют оригинальные фотографии; два рекламных кадра созданы Imagegen по образцам настоящей одежды и отмечены как AI-концепт.

Неофициальная инициатива, не связанная с Thor Steinar или MediaTex GmbH. Не опубликована. Нет реальных заказов и платежей.

## Запуск

В папке проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

На Windows можно использовать pnpm.cmd. Проверенная среда: Node.js 24.22.1, pnpm 11.25.0.

## Сборка и хостинг

```sh
pnpm build
pnpm check
pnpm preview --port 4173
```

Готовая сборка — dist. Для статического хостинга загрузите содержимое dist в каталог сайта. Пути относительные; серверная часть не нужна. Не открывайте index.html двойным щелчком — используйте HTTP-сервер.

## Функции

Поиск, категории, Herren/Damen, Neuheiten, избранное, просмотр оригинального товара, обязательный выбор демонстрационного размера, демо-корзина, количество, удаление и отмена удаления. Выбор хранится локально. Цены и наличие смотрите по ссылке конкретного оригинального товара; их актуальность в концепте не имитируется. Демонстрационные размеры не обозначают складской остаток.

## Материалы и права

Оригинальные фотографии и логотип взяты с официального сайта по запросу владельца концепта. Их права остаются у правообладателей; перед публичным коммерческим использованием получите необходимые разрешения. Оригинальные товарные фото не заменялись генерацией. В шапке оригинальный знак показан в белом монохромном варианте средствами CSS.

Генерация моделей не гарантирует полного совпадения каждой детали одежды. Основой служили EIKIN II и Damen SUPPORT. AI-кадры не являются официальной кампанией. Тексты включают названия, подтверждённые составы, короткие фирменные фразы и авторские немецкие переформулировки. История, отзывы и достижения бренда не выдумывались.

Источники, ссылки и точные запросы Imagegen: docs/brand-sources/manifest.json. В public/images/brand находятся используемые изображения; происхождение сохранено в метаданных либо сопутствующих JSON-файлах. Шрифты Barlow и Barlow Condensed локальные, лицензия OFL приложена.

## Проверка пробника

Сборка и проверка ресурсов прошли. В браузере проверены шесть ширин 1920/1440/1024/768/390/375, поиск, фильтры, новинки, выбор размера, избранное, сохранение, корзина, количество, удаление/отмена, Escape и удержание фокуса. Горизонтальной прокрутки не найдено. Отчёт независимого технического audit — docs/brand-audit.md; старые QA.md и design-direction.md относятся к предыдущей версии.

По просьбе пользователя дополнительные проверки и отдельный финальный дизайн-review прекращены: это пробник. Физические телефоны, Safari/Firefox, экранные дикторы и реальная оплата не проверялись. Платёжной функции нет.
